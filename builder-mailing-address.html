Set up · Mailing Address

What address will you collect?

Tick Displayed for each field you want on the application, and Required for the ones the applicant must fill in.

Anything displayed but not required is optional for the applicant. Anything not displayed is never asked for and never stored.

The panel on the right is the applicant’s view of this section, and it updates as you tick. It is a picture of the form, not the form itself, so nothing in it can be typed into.

Pick fields

Field Description Displayed Required
Address Line 1 Always collected and required Street number and name
Address Line 2 Apartment, unit or suite
City Always collected and required Town or city name
State/Province/Region Always collected and required Picked from a list, so it cannot be mistyped
Zip Code or Postal Code Always collected and required Five digits, or a postal code outside the US
Ward Local electoral ward, where your agency tracks it
County County the address falls in
Country Only worth asking if you accept addresses outside the US

A licence has to be postable, so the street, city, state and zip of the mailing address are always collected and always required.
