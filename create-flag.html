Definition

A flag definition is the agency-wide template for a condition that can be raised on a record. Fields marked Required must be completed.

Give the definition a name in uppercase letters, numbers and underscores, for example INSURANCE_EXPIRATION, that is unique within your agency, then choose the category that matches how the flag is raised: Timer, Expiration and Event flags are raised automatically by rule, while Manual flags are applied by staff from a constituent profile. The label is what staff and constituents see wherever the flag appears. The name and category cannot be changed once the definition is created.

Behavior

An inactive definition stays on record but is no longer raised automatically or offered in the constituent profile flag picker. When Blocks Submission is set to Yes, a constituent carrying this flag cannot submit until it is cleared.
