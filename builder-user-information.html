Set up · User Information

Now decide what you ask the applicant

The application itself is set up. What is left is the information the applicant hands over.

The application details are saved. Drafts stay in the Drafts area of your dashboard, so you can leave and come back at any point without losing this work.

The next four steps decide what the applicant is asked about themselves. On each one you tick the fields you want on the application, and the panel beside the list shows those fields the way the applicant will see them.

What you’ll set up next

  1. 1
    Personal Information Name, prefix and suffix. First and last name are always collected.
  2. 2
    Contact Information Phone numbers and email address. The email address is the applicant’s sign-in, so it is always collected.
  3. 3
    Mailing Address Where post is sent, and optionally a physical or alternate address as well.
  4. 4
    Demographic Information Optional detail your agency reports on. You choose what goes inside each dropdown as well as whether it appears.

A few fields are collected on every application and cannot be switched off. Those rows are marked, with the reason next to them.
