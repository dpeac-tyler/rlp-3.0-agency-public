Set up · External Integration

Add an external verification check

Child Support Payment Verification is the one external lookup available to an application today.

Turn the lookup on and the applicant is asked for the details it needs to run, and the result comes back to the reviewer as part of the review process. Leave it off and this step adds nothing to the application.

Turning it on also means writing the Child Support Verification Text, which tells the applicant why their child support status is being checked. You write it here, on this step, and it is required before the application can go live.

Required indicates a required field.
