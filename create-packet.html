Packets group an owner application type with one or more participant application types. When a packet is created, the owner applicant completes the owner application, after which affiliated users are prompted to complete the associated participant applications. Each participant application can be marked as Required, meaning it must be completed before the packet can be submitted, or Optional, allowing it to be skipped. At least one required participant application must be defined before a packet can be saved.
