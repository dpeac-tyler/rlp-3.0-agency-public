Set up · Task Management

Set up the review process

Define the tasks a submission passes through, and which user group can review each one.

A task’s assigned user group can claim, approve, reject, deny and unclaim it. Tasks run in the order they appear below, so the order you add them in is the order reviewers work through them.

If you need to check which user groups exist first, open Settings › Users / Groups in a separate tab so you don’t lose this draft.

Required indicates a required field.

  1. 1

    Would you like Standard or Agency Defined task naming? Required

    Standard names each task for its place in the queue, so a two-task process reads Task 1 of 2, then Task 2 of 2. The names keep themselves up to date as you add or remove tasks.

    Agency Defined lets you pick each name from the list your agency maintains.

  2. 2

    Add the tasks in your review process. Required

    You can add up to five tasks. Each one needs a user group before the application can go live.
