Set up · Form No., Deactivation & Search Terms

Number this application and help people find it

Nothing on this step is required. You can set any of it now, or come back to it before the application goes live.

The form number is usually the same number that appears on the paper version of this form. Once the application goes live the number is locked, so it can no longer be edited.

The application deactivation date is the last day this application is available online. It has to fall on or after both today and the go-live date.

  1. 1

    Type the Form Number in the field below.

    Matches the number printed on the paper form, if there is one.
  2. 2

    Set the Application Deactivation Date.

    Leave this blank to keep the application online until you retire it yourself.

  3. 3

    Type in the search terms that users can use to search for this application on the internet.

    Type a comma-delimited set of search terms that citizen users may use to search for this application on the internet. Search terms may be single or multiple words.

    1000 characters left
  4. 4

    Choose whether this application is promoted on the portal landing page.

    Left off, applicants can still reach this application through search and through a direct link.
